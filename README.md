# Nolan Chess

Экспериментальный движок шахмат с инверсией фигур в духе «Довода».
История хранится как мировые линии фигур; доска — их срез по времени.
Графического интерфейса пока нет.

Направление времени выбирается для каждого хода вместе с пространственным
перемещением. Игрок может выбрать любой доступный обычный или реакционный ход;
обязательного порядка досок нет. После пространственного хода очередь переходит
сопернику; при отсутствии действий она может автоматически вернуться.
Ход на времени `t` гасит реакции своей стороны на досках `<= t`, сохраняя
обычную доступность вне разыгранного слота хода.

**Состояние реализации:** работают ходы в прошлое, возвращение в будущее,
вложенные петли и замена прежнего хода. При инверсии внутри истории новые
состояния вставляются в причинном порядке перед сохранённым будущим.
Этот участок согласуется с изменённым прошлым после замыкания петли.
Уход с последней доски не оставляет копию фигуры на новой будущей доске.

Ход вперёд проверяется на `t + 1` (на `t`, только если будущей доски ещё нет),
ход назад — на `t - 1`. Направление учитывается также при поиске новых целей
для реакций. Обычные ходы, взятия, рокировка, en passant, превращение,
отмена зависимых ходов и восстановление фигур покрыты тестами.
Рокировка остаётся только вперёд; ходы назад доступны при `t > 1`.

Шах, включая инвертированную угрозу из будущей доски, сам по себе не заканчивает
партию: победа засчитывается при фактической гибели любой инкарнации короля.
Цикл согласования истории означает поражение автора команды. Пат фиксируется
только при отсутствии доступных действий, угроз королю и обычных долгов
противника в прошлом; иначе игрок ожидает, пока противник изменяет историю.
Обычные права в прошлом можно бесплатно пропускать в текущем направлении
фигуры, только в пределах существующей истории.

## Использование

```rust
use nolan_chess::engine::Engine;
use nolan_chess::model::{Color, Sq, TimeDirection};

let mut game = Engine::default(); // Сразу содержит доску и индексы.
let pawn = game.move_sources()
    .find(|piece| piece.t == 0 && piece.sq == Sq(4, 1))
    .expect("white e-pawn");
let mv = game.possible_moves(pawn.origin, pawn.age)?
    .into_iter()
    .find(|mv| mv.sq == Sq(4, 3) && mv.direction == TimeDirection::Future)
    .expect("e2-e4");

game.apply_new_mv(mv)?; // Ход, согласование истории и смена очереди атомарны.
assert_eq!(game.turn(), Color::Black);
assert_eq!(game.board(1).unwrap().get_piece(4, 3).unwrap().origin, pawn.origin);

let restored = Engine::from_history(game.history().clone(), game.turn())?;
assert_eq!(restored, game);
# Ok::<(), nolan_chess::engine::EngineErr>(())
```

`move_sources()` перечисляет доступные состояния фигур на всех досках для
текущего игрока. Для сценариев и тестов есть `State::new` и
`Engine::from_worldlines`; после построения движка история доступна только на чтение.

Новые команды и запросы:

- `skip_ordinary(source: PieceAt, to_t)` — бесплатное ожидание выбранной фигуры.
  Не меняет её клетку, направление и флаг `moved`, не расходует права других
  фигур. `to_t == source.t` просто снимает её обычное право.
- `checks(color)` — обычные и инвертированные угрозы королям, с указанием `PieceAt`.
- `status()` — `Ongoing`, `Waiting` или `Finished`; `outcome()` — победа
  (`KingCaptured` / `Paradox`) либо `Stalemate`.

После каждой команды следует проверять `outcome()` и `turn()`. Поражение от
парадокса возвращает `Ok(())`: результат записывается, а доски сохраняются
в последнем согласованном состоянии. После завершения команды отклоняются
с `EngineErr::GameOver`. Результат и ожидание входят в снимок `History`.

Подробнее: [модель, инварианты и дальнейшая разработка](docs/architecture.md).
